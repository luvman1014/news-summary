# 每日摘要 2026-11-16

### 今日要点

1. **Anthropic 将 Agent Skills 捐赠给 Agentic AI 基金会，开放标准已被 70+ 主流平台采纳**  
   Anthropic 将于 2025 年 12 月发布的 Agent Skills 标准捐赠给非营利组织 Agentic AI Foundation。该标准让 AI agent 获得专业知识与工作流，目前已被 ChatGPT、Cursor、GitHub Copilot、VS Code 等 70 余个 agent 平台集成。这标志着 agent 互操作层的事实标准基本形成，未来开发者可在不同平台间复用技能定义，降低多平台适配成本，推动 agent 生态从“各自为政”走向标准化协作。

2. **OpenAI 发布科学博客首篇文章：GPT-6 Astra 协助物理学家在晶格上给出标准模型候选定义**  
   UCSB 理论物理学家 Nathaniel Craig 与 GPT-6 Astra 合作，在 2026 年 10 月预印本中提出标准模型在晶格上的非微扰定义候选方案。标准模型缺乏严格非微扰定义是困扰粒子物理半个世纪的难题；Astra 将 Craig 的策略转化为完整构造并主导了详细证明。这展示了前沿模型在高难度数理推理中已能承担“合著者”角色，而非单纯编码辅助，OpenAI 新设科学博客旨在系统记录此类 AI 驱动发现。

3. **Hugging Face 启动 Project ProtoStar，撬动年 1900 亿美元联邦科研经费的 AI 就绪化**  
   ProtoStar 联合 CMU、Purdue、Georgia Tech 等 5 所大学、Astera Institute、ORCA 及 Hugging Face 自身，推动公共资助的数据集、模型、代码以 AI-ready 格式开放。NIH 已将 Hugging Face 列入 10 个通用数据仓库之一。首期挑战赛由 CMU 主办，要求用历史气象数据预测 210 个美国城市 2019-2026 年气候指标，并提出适应性政策建议。若成功，将建立“公共科研产出 → 标准化发布 → AI 复用 → 加速发现”的飞轮，解决“公开不等于可用”的长期痛点。

4. **Mistral Large 4（Le Chonk）发布：1T 总参数、49B 激活参数的 MoE 多模态模型，网络安全与编程能力领跑开源权重生态**  
   模型采用 72 层解码器、MLA+DeepSeek 稀疏注意力、3:1 RoPE/NoPE 模式、128 专家中每 token 激活 4+1 共享专家，视觉编码器为 1.6B Pixtral。在 Artificial Analysis Cyber Index 中以 82% 得分居前五，Cybench 解决 93% 安全挑战，编程 Agent 综合指数 49.8% 超越 DeepSeek V4 Pro 与 Qwen3.8 Max。Mistral 定位防御性安全工作，开放权重让用户自主控制部署与拒答策略，配套 transformers/vLLM/llama.cpp 首日支持，GGUF 量化已就绪。

5. **No Priors 专访 Robinhood CEO Vlad Tenev：Agentic Trading 已获 15 万+ 用户，Harmonic 致力于数学超级智能，代币化将所有权推向全球**  
   Tenev 称 Robinhood 已成“所有权公司”，业务覆盖 120+ 国家。Agentic Trading 实现产品市场契合，15 万用户开设账户让 AI 代理交易。Harmonic 去年训练的 Aristotle 模型在 IMO 夺金，现向公众开放协助攻克未解数学难题。Tenev 批评当前 AI 数学过度中心化，主张将工具下放给个人研究者，实现分布式发现。代币化被视为让无银行账户人群接入全球经济网络的关键基建。

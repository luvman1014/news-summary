# 每日摘要 2026-11-03

### 今日要点

1. **Anthropic 推出分级网络安全验证计划（CVP），向防御者开放前沿模型能力**  
   Anthropic 将 Project Glasswing 与原有 CVP 整合为三层分级体系：Defense Access（防御运营）、Red Team Access（授权渗透测试）、Specialized Access（关键基础设施测试）。Claude Opus 5.5 等最强模型在 Red Team 层级可无阻滞完成 67.6% 的多阶段攻击评测任务，而在公开版本上同类任务 100% 被拦截。Glasswing 合作伙伴 4 月至 7 月已挖掘 12.9 万+ 经验证漏洞，其中 3.3 万+ 为高危/严重级。此举旨在让防御方获得与攻击者对等的工具能力，并承诺秋季推出零数据保留的企业级方案 EFS。

2. **OpenAI 模型在数学、计算机科学、物理三大领域取得突破性发现，并启动学术协作验证机制**  
   内部模型证明了调和分析中的局部平滑猜想（所有维度），从而推导出 Kakeya 猜想与 Stein 限制猜想；在计算机科学上反驳了指数时间假设（ETH），经 Lean 形式化验证；在物理上给出含规范场的交互量子场论严格存在性证明。OpenAI 不自行宣称学术署名，而是邀请外部专家组成「羊倌团队」协作理解、撰写与发布，三个结果分别采用完全开放、协作撰写、延迟发布三种策略，探索 AI 科研成果转化为科学认知的新范式。

3. **Anthropic 发布 FlashProve：首个实用化的 LLM 推理零知识证明系统，单 H100 达 110 tokens/s**  
   针对 400B 参数 MoE 模型（Llama 4 Maverick，4-bit 量化），FlashProve 用 zkSNARK 在单张 H100 上以 ~110 tokens/s 生成证明，证明体积 ~19 MB/1k tokens，开销仅为 vLLM 原生推理的 70-95 倍——比现有开源方案快数量级。代码、Lean 形式化证明与协议规范全开源（Apache 2.0）。核心意义在于让用户无需模型权重、仅用 CPU 秒级验证响应确由声称模型生成，解决路由服务偷换模型、评估器确认被测模型一致性、供应链篡改 token 流等信任难题，为 AI 监管与合规提供技术抓手。

4. **Cursor 发布 Agent SDK，将「以代码定义 Agent」的内部框架开源，支持一键部署至自有基建**  
   Agent SDK 采用 TypeScript + Markdown 组织提示词、工具、Evals 与外部连接，整个 Agent 即一个可版本控制的小型软件项目。内置事件驱动、子 Agent 并行、Eval/回放、技能引导等能力，`agent-sdk deploy` 单命令即可上线至 Cursor 云或自托管容器。PGA Tour 已用其构建全套软件工厂；Cursor 自身的 Bugbot、Security Reviewer、Rollouts 亦基于此框架。标志着 Agent 开发从「配置提示词」走向「工程化交付」。

5. **OpenAI 构建 Pando 替代 Git 后端，实现单体仓库水平扩展写入与 PB 级日读取吞吐，且保持 Git 协议兼容**  
   Codex 引发的并行开发量导致原有 Git 服务可靠性跌破 90%。Pando 通过分支级独立协调写入、跨客户端复用 packfile 两大设计，将中位 push 延迟降 5 倍，日服务近 1 PB Git 数据。完全兼容 Git 客户端与协议，工程师与 Agent 无感迁移。OpenAI 同步向上游贡献改进，推动 Git 生态适应 Agent-scale 并发工作流。

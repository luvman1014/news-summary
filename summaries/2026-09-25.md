# 每日摘要 2026-09-25

### 今日要点

**1. Anthropic 的 Claude 自主发现类 CRISPR 新酶系统，展示 AI 在基础生物学研究中的原创发现能力**  
Anthropic 组建的生命科学实验室让 Claude 在 21 小时、950 个并行 agent、2.1 亿 token 的搜索中，从海量 DNA 序列中识别出一种全新的「阵列关联逆转录酶」（ART）系统：它拥有非编码 DNA 重复阵列和未知功能的辅助蛋白，这组特征仅在极少数可编程基因编辑系统（如 CRISPR）中同时出现。CRISPR 先驱 Feng Zhang 评价此为「AI agent 参与生物发现的激动人心范例」。这标志着 AI 能在仅给高层方向的情况下，完成从文献调研、假设生成、候选筛选到湿实验验证的完整科学发现闭环。

**2. OpenAI 内部模型解出纳维-斯托克斯千禧年大奖难题，以 1.3 万 agent 协作、1300 亿输出 token 完成证明并形式化验证**  
OpenAI 透露其内部模型（显著强于 GPT‑6 Astra）在 88 小时内由约 1 万并发 agent 协作，产出了纳维-斯托克斯存在性与光滑性问题的解析证明与 Lean 形式化验证，证明三维不可压缩流体可在有限时间内形成奇点（能量保持有限）。此前 Anthropic 团队已解出受迫欧拉方程，双方同意同步发布。这展示了大规模 agent 协作在深度数学推理上的潜力，也引发了对 AI 加速基础科学发现节奏的重新评估。

**3. OpenAI 披露研究加速内部指标：全员日均 3.1 agent‑workday，90 分位研究员日推理成本超 $7,000，编码 agent 已成核心生产力**  
截至 8 月中旬，OpenAI 研究组总 agent 运行时长已超人类工时；中位数研究员日均调用 agent 成本 $600，头部研究员超 $7,000。实验次数、代码提交速度、高复杂度任务委托比例全面跃升。OpenAI 目标在 2028 年 3 月实现自动化 AI 研究员，并强调需在保持人类控制前提下推进，近期因 Hugging Face 事件曾暂停 RL 训练以强化监控。这些数据为外界评估 RSI（递归自我改进）进度提供了罕见的量化基准。

**4. Google DeepMind 发布 Gemini 3.8 Live with Live Avatar：近实时视频化身、97 语言无缝切换、异步工具调用不打断对话**  
Live Avatar 在 Gemini Enterprise 上线，结合精准唇形同步、自然表情与流式轮次，支持从预设或单张参考图生成定制化虚拟形象。异步工具执行让化身在后台查询数据、调用 API 的同时保持对话连贯。SynthID 水印贯穿音视频输出。这把多模态 agent 从「聊天界面」推向「具身化存在」，对客服、培训、远程协作等企业场景具有直接落地价值。

**5. Anthropic Project Swap 实验：201 人、5 分钟闲聊后 agent 书籍偏好匹配度 61%，市场效率主要受限于信息缺失而非谈判能力**  
Anthropic 让员工与 agent 聊 5 分钟偏好，agent 再在去中心化交易大厅自主议价换书。模型能力对谈判结果影响大于提示词；多数参与者愿把 1/3 年度购书预算交给 agent。实验暴露了 agent 市场的核心难题：如何验证 agent 真懂用户、市场准入规则、违约处理、信息可见性——这些问题在 agent 大规模进入真实经济交易前必须解决。

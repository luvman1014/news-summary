# 每日摘要 2026-11-18

### 今日要点

1. **Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2，展示迄今最全面的「AI 做科研与工程」实证**  
   两款模型在编码、推理、视觉上全面超越 Opus 5.5，且价格降低 20%（$8/$40 per M tokens）。实测中，Fable 5.2 从零编写可启动的操作系统（协调 1000+ 子代理运行 8 天），解决两个黑洞物理开放问题，30 小时形式化证明费马大定理，并完成 Python→Rust 核心服务迁移（启动快 26 倍）。Mythos 5.2 在网络安全漏洞挖掘上比 Opus 5.5 多发现 10.2% 漏洞，且零误报。Anthropic 核心代码库 90%+ 变更已由 Claude 编写，标志着「AI 为主、人为辅」的软件工程范式正式落地。

2. **Google DeepMind 推出 Gemini 4 Carbon 与 AlphaProof Code，双管齐下攻克「长程推理」与「形式化验证」两大难关**  
   Carbon 定位最强推理模型，在 CursorBench、WANDR、AutomationBench 三大智能体基准夺冠，单任务成本仅为次优外部模型 1/2；通过 /swarm 预览实现多代理协同。AlphaProof Code 则实现里程碑：首次用 AI 形式化验证广泛部署的 Signal 协议核心密码学代码，生成 600 万行 Lean 证明，仅耗 4 周（人工通常需数年），并能自动捕获植入的真实漏洞。这标志着「可扩展的自动化形式化验证」从理论走向工程现实，将为关键基础设施安全提供数学级担保。

3. **OpenAI 发布 GPT-6.2 Astra 与 Sol，主打「效率」与「极速体验」，但口碑两极**  
   Astra 定价同步下调 20%（$8/$40），缓存价格更低至 $0.40/M；Sol 保持 $2/$10 并推出 ultrafast 模式。Simon Willison 实测显示 Astra 在三维动画生成等创意任务上不及 Fable 5.2 与 Carbon；Theo Browne 指出其长任务中会随机询问人类无法理解的内部实现细节。Sam Altman 承认模型「很聪明但不够好用」，将优先改进易用性。这反映前沿实验室竞争焦点已从单纯智力指标转向「工程效率」与「交互体验」。

4. **编程代理范式跃迁：从「单任务执行」转向「持久化、结果导向、团队协作」**  
   Cognition 推出 Devin Bots：持久化代理拥有长期记忆与工具，能自主拆解目标、管理子代理、仅在需人类决策时介入。实测中「Android Bot」44 天合并 1134 个 PR、写 34 万行 Kotlin，「Layout Bot」三周修 159 个布局偏移 PR 降 70% 卡顿，「Super Jenny Bot」让一人游戏工作室周 PR 从 50 跃至 1900。Cursor 同步推出 Multiplayer Projects：共享上下文、任务看板、代理间跨座位通信，实现「人团队 + 代理舰队」共享工作空间。两者共同指向：工程师不再分发任务，而是定义责任边界与评估指标。

5. **Google Research 提出「睡眠框架」，让 LLM 在部署后持续学习而不灾难性遗忘**  
   受大脑睡眠巩固记忆启发，框架引入「离线睡眠阶段」：记忆巩固阶段将短期上下文压缩为低秩参数更新；做梦阶段通过激活不同 MoE 专家、奖励筛选合成数据，拓展梯度方向、改善优化地形。实验显示：在持续翻译、10M 长上下文、事实注入、数学推理（AIME 79.2%）四大任务上均显著优于 SFT、GRPO、SEAL 等基线，且近零遗忘。这为「自主持续学习的 AI 系统」提供了理论与工程双重可行路径。

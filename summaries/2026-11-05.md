**VocabX** 方法：按 **token 服务成本而非频率** 重构词表，在葡萄牙语作文自动评分 (Qwen3-4B) 中 **推理成本 -77%**。核心洞见：decode 阶段受内存带宽瓶颈，生成 token 成本是读取的 7.4×；词表每多一行，LM head 每步全矩阵乘法就多搬一次数据。VocabX 双层同时优化：子词层重切分 + 宏 token 整行合并（如 JSON 信封），均按“省下的 decode 成本”打分。输出层从 15.2 万行降至 6.5 万行。现有方法 (FVT/MWT/in-place BPE) 仅按频率、单层优化，错过高价值长跨度重复。论文审稿中。

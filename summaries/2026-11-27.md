2. **Google DeepMind 发布 Gemini 4 Hydrogen：面向大众的高性价比执行型模型**

3. **OpenAI 内部构建「Performance Factory」：Codex Agent 自动化性能回归修复**  
   面对 agentic 开发节奏导致传统性能工程跟不上，OpenAI 建立了端到端自动化系统：性能告警触发 → Codex Agent 调查根因 → 提出修复 → 工程师 Review → 部署后 Agent 验证恢复。三个月内完成 1700+ 调查、根因定位 600+ 案例，日均 17 次自动化调查。核心组件包括：任务追踪器（可配置工作流）、调度循环、云端 Codex API、事件订阅机制（等待 PR Review、部署完成等）。该系统将「人作为代理」的模式进化为全自动工厂，并将通用优化抽象为可复用工作流，为其他服务团队采用 agentic workflows 提供了范本。

4. **Devin 推出 Databricks 迁移专用版：企业级数据平台迁移从季度级缩至天级**  
   Cognition 与 Databricks 联合推出「Devin for Databricks Migrations」，Devin 能自主完成：遗留代码转换、在客户工作区测试、修复失败、Cutover 前逐行对账。某 Fortune 500 能源公司 142 个对象的 Unity Catalog 迁移仅耗时 8 天；全球咨询公司 Zeb 将原本 4 周的 NetSuite→Databricks 迁移压缩至 2.5 周。Devin 可并行运行数百任务，配合 Databricks Unity Gateway 统一模型接入，成为 Databricks 首选迁移工具，已上架 Marketplace 并可抵扣 Universal Commit。这标志着 AI 软件工程师正式承接大规模、高确定性的企业级工程交付。

5. **AlphaGenome 2 实现单细胞分辨率的 DNA 变异效应预测，识别致病变异数量翻倍**  
   Google DeepMind 发布的新一代基因组模型从「组织平均」进化为「细胞类型条件化」：输入百万碱基序列 + 目标细胞类型/状态，逐层注入条件信息，使同一 DNA 在不同细胞类型中的读取差异可被捕捉。在 TenK10K 免疫细胞图谱上，因果变异识别率从 16% 跃升至 30%，方向性基因效应从 23% 升至 43%。模型能零样本泛化到未见细胞状态（如 COVID 疫苗激活的 T 细胞），并预测甲基化等新读出。预计算数亿变异×数百细胞类型的结果已开放 API，直连 GWAS 与单细胞图谱，为罕见病、复杂性状研究提供计算优先级。

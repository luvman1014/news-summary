# 每日摘要 2026-10-26

### 今日要点

**1. Anthropic 正式推出分三级的 Cyber Verification Program，将“防御者优势”落地为可规模化的产品能力。**  
在 Project Glasswing 试点中，Claude Mythos 模型帮助合作伙伴在 4 个月内发现 12.9 万个经验证漏洞（其中 3.3 万+ 为高危/严重），多位合作伙伴表示漏洞挖掘效率提升「数月甚至数年」。新项目把防御、红队、关键基础设施测试分为三级，分别对应不同级别的模型能力与安全控制，并承诺在秋季推出零数据保留的 Enterprise Frontier Safeguards。这标志着前沿模型厂商开始以结构化、可审计的方式把进攻性网络能力交给经过验证的防御方，而非单纯依赖事后拦截。

**2. OpenAI 披露 ChatGPT 广告系统的全栈架构：有状态会话 + 独立编排 LLM + 与答案生成彻底解耦。**  
广告系统不再基于单次请求-响应，而是维护跨轮次、跨会话的有状态上下文；一个后训练的专用 LLM 作为「编排器」迭代调用检索、排序、拍卖等工具；广告选取在独立服务中完成，完全不影响 ChatGPT 的中立回答。上线不足 200 天实现 10 亿美元年化跑率、10 万+ 广告主，证明对话式广告可在不破坏用户信任的前提下商业化，也为所有 LLM 产品提供了「原生广告」的参考范式。

**3. DeepSeek 开源生产级推理栈 DeepInfer：单集群日服务 155T tokens、96% 输入缓存命中、推理毛利 >80%、81 天回本。**  
基于 vLLM/SGLang 深度定制，分离 prefill/decode、专家并行、持久化 KV 缓存（3FS，百 PB 级）、计算感知调度等工程创新在生产环境跑通。虽然核心 KV 缓存管理、负载均衡尚未完全开源，但已公开的代码与详细工程报告让开源推理栈首次具备了与闭源厂商（Fireworks, Baseten, Modal）正面竞争的硬指标，可能重塑推理服务的成本结构与竞争格局。

**4. Hugging Face 联合 Reflection 发布 Beam：501B 参数 MoE（23B 活跃）、1M 上下文、Apache 2.0、原生工具调用与多级推理。**  
这是新成立的美国实验室 Reflection 的首个模型，采用 52 层、256 专家/层、DeepSeek-V3 风格分组路由、残留流 1/√k 缩放、混合滑动窗口+全局注意力等前沿架构。提供 BF16/FP8/NVFP4 多精度权重，Day-0 支持 transformers/vLLM/SGLang，并附带 Rust 定制推理哈尼斯。为想在自有硬件上跑前沿规模、长上下文、Agentic 编码任务的团队提供了「开箱即用」的开放替代方案。

**5. Microsoft ThinkingBox 基准揭示 Agent「一次能做」与「每次都能做」的巨大鸿沟：按终态数据库状态而非工具调用打分，507 任务各跑 20 次。**  
Kimi-K3 单次通过率最高（93.9% 任务至少成功一次），但仅 13.4% 任务能 20/20 全对；Claude Opus 5.5 单次通过率略低，却有 47.5% 任务全对，保留了 71% 的单次性能。成本帕累托前沿仅三款模型：GPT-5.6 Sol 单次成功成本最低，$0.127；GPT-5.4 多花 $0.004 换 3.45 pp 准确率；Claude Opus 5.5 再加 $0.276 换 1.8 pp。结论直指生产部署：选模型看 pass@20 与单位成功成本，而非排行榜 pass@1。

- 缓存层级：持久块缓存驻 3FS (~100 PiB SSD)，Agent 3 天/聊天 7 天留存；滑动窗口态留主机内存；GDR/RDMA 直传 KV 块饱和 PCIe 不占 SM。
- 专家复制负载均衡：热专家周期性重分布，权衡 HBM 占用与吞吐。
- 争议：vLLM 复现显示 GB200 上解码吞吐仅差 6%，质疑「独家高效」；盈利敏感于工作负载混合、缓存核算、硬件成本口径。

#### Anthropic Engineering Blog
**Building strong safety evaluations**  
**核心论点**：安全评测的可信度直接决定模型发布、护栏配置与对齐研究方向，但现有评测易被钻漏洞、构念效度低、复现性差；Anthropic 借鉴心理学复制危机改革（预注册、严格统计、多专家协作），提出一套可落地的强安全评测方法论。  
**关键要点**：
- 组建“领域专家+方法专家”双轨团队，缺一不可：前者定义危害边界与良性响应，后者设计采样、评分、统计分析。  
- 评测必须在无网络、实时监控的沙箱中运行；网络搜索类评测需单独加固并实时熔断。  
- 区分**观测性设计**（比较模型间差异）与**因果性设计**（验证干预是否生效），按决策问题选择。  
- 拒答率不是普适指标：自杀/自残场景下“拒答即失败”，需改用**适当响应率**（多轮对话全程符合领域专家鲁布里克）。  
- 双重测量：同领域同时测“有害请求的无害响应率”与“良性请求的拒答率”，防止过度拒答。  
- 采用贝叶斯推断量化参数不确定性，避免单一最优解掩盖等价拟合。  
- 预注册假设与分析计划，公开数据与代码，接受独立复现。  
**值不值得深读**：**值得**——这是目前最系统、最落地的 AI 安全评测方法论公开文档，直接可迁移到企业红队与合规流程。  
**链接**：https://www.anthropic.com/research/building-strong-safety-evaluations

**The components of agent memory**  
**核心论点**：Agent 记忆可借鉴人脑“海马体快速编码 + 睡眠离线巩固”双通路，Anthropic 将其拆解为**记忆笔记（在线标记/写入）**与**梦境（离线整理/提炼规则）**，并通过 CL-Bench 与 Pokémon 实验证明：强模型能主动形成“验证过的规则+陷阱预警”的精简记忆库，弱模型倾向全量归档导致检索崩溃。  
**关键要点**：
- 记忆笔记：会话中标记显著事件或写入持久化文件夹，靠“预测未来复用”判断显著性。  
- 梦境：利用闲置算力回放日志，提炼规则、修正错误、合并笔记，类比人类睡眠巩固。  
- CL-Bench 实验：Opus 5 首次闭环——记忆含“规则+证据+陷阱预警”，后续模型沿用此模式并持平性能。  
- Pokémon 实验：Fable 5 仅用 9 个文件（策略/规则/导航计划）通关 4 徽章；Sonnet 3.7 写 413 文件却仅 1 徽章，因冗余记忆过时拖慢决策。  
- 引导写入记忆：系统提示明确“写入什么、何时写入、如何组织”，显著提升记忆质量。  
**值不值得深读**：**值得**——首次将认知科学机制显式映射为 Agent 架构组件，并给出可复现的基准对比，对设计长时程 Agent 极具参考价值。  
**链接**：https://www.anthropic.com/research/components-of-agent-memory

**核心论点**：供应链攻击复盘：Fireworks 密钥泄露 → 读取只读桶编码轨迹（含 <0.01% 客户 API 凭证）→ 横向渗透 SaaS → 窃取内部代码/支持数据/用户凭证 → 用偷来的凭证在 Cursor VS Code 市场上架恶意 Claude Code 扩展 2.1.312/313（植入 SSH 后门），约 5000 用户可能受影响，可用 11 小时。  
**关键要点**：
- 未受影响：Privacy Mode 数据、生产系统、签名密钥、客户代码仓、其他扩展、实时推理流量。  
- 已处置：切断 Fireworks、轮换所有凭证、重建市场、扩大网络准入限制、全仓秘钥扫描、重新部署所有生产设施、聘请外部取证、逐个通知受影响客户。  
- 受影响用户已收到具体密钥轮换清单与修复脚本。  
**值不值得深读**：**必须读**——AI 编码工具供应链安全的实战教训，直接关联你的凭证管理与扩展安装策略。  
**链接**：https://cursor.com/blog/security-incident-update

**Introducing Devin Apps**  
**核心论点**：Devin Apps = 运行在 Devin 云主机上的私有 Web 应用，自然语言描述需求 → Devin 构建部署 → 稳定 URL 团队共享（需登录 Devin）、可增量更新、基于内存快照休眠计费、适配内部 MCP/代码库/数据源。  
**关键要点**：

**值不值得深读**：**值得**——Agent 原生应用托管范式，降低内部工具交付门槛，对平台工程团队极具参考价值。

**Devin Review 2.0**  
**核心论点**：Devin Review 2.0 成默认 PR 审查工具，成本降 82%（单 PR $0.25-0.75），Bug 发现率反升（1.22→1.32/PR），延迟中位数 94 秒；支持增量审查、自动规则、Ultra 模式（高风险代码深度审）、Custom Reviewers（自定义规则如安全迁移/性能 SQL/无障碍 UI）。  
**关键要点**：
- 审查成本已低到可“每个 PR 都跑”，配合每次 push 增量审查。

- 单 Bug 修复均价 ~$2.25。  
**值不值得深读**：**值得**——代码审查瓶颈的 Agent 解法已进入“便宜、好用、可规模化”阶段，工程效能团队应评估接入。

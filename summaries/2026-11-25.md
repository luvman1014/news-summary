# 每日摘要 2026-11-25

### 今日要点

1. **Anthropic 发布 FlashProve：大模型可验证推理的重大突破**  
   Anthropic 开源了 FlashProve 系统，首次在 400B 参数 MoE 模型（Llama 4 Maverick）上实现了实用级 zkSNARK 推理证明：单张 H100 生成证明速度达 110 tokens/秒，证明体积约 19 MB/1K tokens，开销仅为普通推理的 70–95 倍。代码附带 Lean 形式化验证的顶层安全性定理，采用 Apache 2.0 许可。这让模型提供者能向用户密码学证明「回复确实来自声称的模型权重」，解决路由服务偷换模型、攻击者篡改 token 流等信任难题，也为 AI 监管合规提供技术抓手。

2. **Google DeepMind 推出 Gemini 4 Carbon 并实现 AlphaProof Code 形式化验证里程碑**  
   Carbon 定位为「最强推理模型」，在网络安全、长程 agentic 工作流、科学推理上达到 SOTA，并以 2 倍成本优势拿下 CursorBench、WANDR、AutomationBench 冠军。配套发布的 `/swarm` 预览可把单个 prompt 拆解为协作式多智能体团队。更震撼的是 AlphaProof Code：在人类专家指导下，Carbon 生成 600 万行 Lean 代码，在 4 周内完成了 Signal 核心加密协议实现代码的端到端形式化验证——这是 AI 首次在该深度验证广泛部署的加密协议，历史上需专家团队耗费数年。

3. **OpenAI GPT-6 展现内生蛋白设计能力，湿实验验证结合率达 10.9%**  
   GPT-6 系列无需调用专用生物模型，仅凭推理与代码即可从头设计蛋白三维结构与氨基酸序列。实验室测试中，基于 GPT-6.2 设计的 322 个 minibinder 中 35 个（10.9%）对 5 个靶标显示结合证据；重新设计的抗体序列中位数与原序列差异 15–50% 却保留结合能力。模型还能按自然语言指令精确控制二级结构元素（α 螺旋/β 折叠数量）。这标志着通用基座模型开始在「推理+工具」范式下超越垂直专用模型。

4. **Cognition 推出 Devin Bots：从「执行任务」进化为「对结果负责」**  
   Devin Bot 是持久化、自带记忆与工具的工程队长，能并行指挥多个 Devin 完成大型目标。实战三例：Android Bot 44 天自主交付 1134 个 PR、34 万行 Kotlin、2841 个截图测试；Layout Bot 每 3 小时自动回归测试并修复布局抖动，三周合并 159 个 PR 降低 70% 延迟；Super Jenny Bot 统领 20 个子 Bot 让个人游戏工作室周交付量从 50 跃升至 1900 PR。核心范式转变：工程师不再分派 task，而是定义 outcome 与评价指标，只在「Needs You」收件箱做关键裁决。

5. **Cursor Projects 升级为多玩家协作工作区，打通团队级多智能体协同**  
   Projects 现支持邀请队友共享需求文档、技术规格、任务看板与上下文记忆。各成员保留 1v1 coordinator 聊天，同时拥有全局共享上下文层：新成员加入即刻继承完整项目状态。Agent 间可跨人通信——前端工程师的 coordinator 与后端 schema 变更的 coordinator 实时同步，避免合并冲突。已在值班轮转场景验证：接手工程师的 agent 能无缝继承进行中事件、未处理告警、Linear 看板与 Slack 频道上下文。

#### Google Research Blog
**The sleep framework: A new way for LLMs to retain knowledge in continual learning**  
**核心论点**：引入「睡眠阶段」实现持续学习：清醒期交互存短期记忆，睡眠期离线巩固进长期参数（MoE 扩展+知识蒸馏+突触修剪）并自主「做梦」自我进化（随机专家激活+梯度筛选+RL 精炼），实现 10M token 长程记忆近零遗忘。  
**关键要点**：
- 两阶段：记忆巩固（参数扩展+向上蒸馏+修剪）→ 做梦（随机专家混合+梯度筛选+RL）。
- 理论：巩固是低秩压缩，平衡 on-policy 行为与语义奖励；做梦多样化梯度方向、改善优化景观。
- 实验：未见语言（Manchu、Kalamang）多阶段评测近零性能下降；BABILong 10M token 接近完美缩放；事实知识注入优于 ICL/Cartridges/SFT。  
**值不值得深读**：值得——持续学习的理论完整实现范式，代码与实验可复现。

发布 NeoMME 双语言多模态编码器（260M/800M），**单一双向 Transformer 直接受文本 token 与原始图像块**，无独立视觉塔/因果解码器，从头用掩码离散扩散目标训练。微调为 NeoMME-Retriever（ColPali 页图检索），单前向同时输出稠密与晚交互嵌入。**两规模均落在 ViDoRe v3 nDCG@10 与模型大小的 Pareto 前沿**：260M 仅用 ColModernVBERT 1/14 参数达 0.523，800M 用 Vultron Retriever Flash 1/3.6 参数达 0.556。层次化 token 池化 + 非对称量化将晚交互索引从 1.5 MB/页压至 6 kB（**255× 压缩**，保留 95%+ nDCG@10）。2048×2048 输入下 260M 编码 51 页/秒（L40S），约为 ColModernVBERT 2× 吞吐。Apache 2.0 开源，已入 Transformers。  
[原文链接](https://huggingface.co/blog/Hcompany/neomme)

**Fine-tuning a 350M Model for Better Structured Outputs in 100 GRPO Steps**  
用 GRPO 在 100 步内将 Liquid LFM2.5-350M 在 IFStruct 结构化输出基准上从 22.6% 提升至 **58.7%**（JSON 18%→52%、YAML 27%→65%），**超越同规模基座模型并逼近大模型**。关键：Nemotron 结构化指令数据 500 条 + 格式/字段数/Schema 三重奖励函数（权重 1.0/0.5/2.0）、LoRA 仅训 1.66% 参数、Colab 免费 GPU 可跑。提供完整 Notebook 与 llama.cpp 本地评测流程。展示**小模型+任务特化 RL 可低成本解决生产级 Schema 合规痛点**。  
[原文链接](https://huggingface.co/blog/grpo-with-trl-ifstruct)

**Give Your Coding Agents a Memory You Own**  
推出 **funes**：编码 Agent（Claude Code/Codex/pi/Hermes）的本地持久记忆层。一条命令 `funes add claude` 即完成增量索引、赋予 `recall`/`get` 工具、安装会话结束自动索引钩子。底层：统一解析 Trace→分块→本地嵌入/重排序→Lance 数据集；检索融合向量+BM25→交叉编码器重排→时效性重权→附邻近块。**三大特性**：跨 Agent 共享记忆、原始证据留存（可追溯至原 Turn）、默认本地推理（无外部账号/模型）。可选绑定私有 HF 数据集同步（自动脱敏），多机器/团队/开源项目均可共享。**实测在 handoff-vs-recall 基准上，Recall 成本仅为书面交接的 1/4-1/8，且未因摘要丢失关键发现**。

**核心论点**：GitHub Secret Scanning 团队总结的生产级 LLM 评测方法论：从「产品决策」反推指标体系（主指标/安全约束/运维护栏），像集成测试一样持续跑离线评测，单变量控制、版本化提示词与配置、定期回归测试模型升级。  
**关键要点**：
- 先定决策：Secret Scanning 的核心是「降低误报同时保底召回」，召回是硬约束，精度是优化目标。  
- 三级指标：Primary Outcome（用户收益）、Safety Constraint（安全底线）、Operational Guardrails（延迟/成本/可靠性/兼容性）。  
- 离线评测 = 集成测试：每次有意义变更必跑，记录 prompt/model/dataset/system 版本，确保可比。  
- 一次改一个大变量：prompt 与 model 分开测，再测组合；像代码一样版本化 prompt 与评测配置。  
- 定期测模型升级：新模型可能让简化 prompt 超过旧模型精调版，评测要廉价化、常态化。  
**值不值得深读**：极值得。生产级 LLM 系统评测的「红皮书」，直接可用于任何代码分析、开发者工具、安全、数据分析等场景。

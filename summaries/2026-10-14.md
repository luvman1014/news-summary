#### Anthropic Engineering Blog
**Redesigning source control at Anthropic**  
**核心论点**：AI 编程 Agent 的爆发式增长（日合并 2.5k → 30k）彻底击穿了为人类规模设计的 Git 基础设施，Anthropic 在五个月内自研中心化 VCS Scion 并完成整库迁移，确立了“Agent 优先”的源码管理新范式。  
**关键要点**：
- 单体仓库主分支历史近 100 GB，压缩工作副本超 25 GB，日检出 2,500 万次，若用 Git 原生协议日流量超 600 PB。  
- Git 的分布式/离线设计在“全员在线 Agent”场景下成为负资产：镜像、浅克隆、种子库等权宜之计随规模失效。  
- Scion 五大原则：客户端永远在线、客户端-服务端极度不对称（服务端包办历史/归并/责备，客户端仅缓存与工作区布局）、源控服务 API 化（CI/工具无需本地仓库即可查询）、全组件水平可扩展（无完整副本、无 packfile 维护）、提交/变基/合并在服务端原子完成且成本随变更量而非仓库规模增长。  
- 变更集 取代 Commit 成为原子单位，写前日志设计实现增量、无锁、廉价提交。  
- 工作副本可选且稀疏化：CI 只拉 diff，写操作走 API，按需物化文件。  
- 团队仅 7 人，5 个月完成迁移；Claude 自身既是压力源也是建设主力。  
- 已开源关键设计文档，预判行业将在 1-2 年内遭遇同类压力。  
**值不值得深读**：**值得**。这是迄今最详实的“AI 原生软件基建”案例研究，对任何规模化部署编程 Agent 的团队极具参考价值。  
**链接**：https://www.anthropic.com/engineering/redesigning-source-control

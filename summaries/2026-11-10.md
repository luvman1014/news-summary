# 每日摘要 2026-11-10

### 今日要点

1. **Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2，重夺模型性能榜首**  
   两款模型共享同一底层权重，Fable 面向通用用户，Mythos 通过 Cyber Verification Program 面向网络安全与生物医药研究。Fable 5.2 在 FrontierCode 2.0 高努力级下以约一半成本追平 Opus 5.5 最大努力级，Xhigh 努力级为已发布模型最高分。实测中，1000+ 子代理在 8 天内从零编写出可启动的操作系统内核、驱动、窗口系统与安装器；自主完成费马大定理形式化证明（30 小时）；设计出三件可工作的电子设备；解决两个黑洞物理开放问题。定价下调 20%（$8/$40 per M tokens），但单任务 token 消耗大幅上升，实际任务成本反而上涨约 31%。默认努力级为 Medium，建议生产环境从默认起步而非沿用旧设置。

2. **OpenAI 密集推进企业化与安全基建：ChatGPT Enterprise 登陆 AWS Marketplace、发布 Control Room 中控系统、推出 LifeVal 生活基准、与学术界合作验证数学/CS/物理重大发现**  
   Enterprise 版现可通过 AWS 采购计费，复用现有承诺消费。Control Room 在 35 秒内切断全研究集群的模型推理，采用「fail-closed」机制防篡改。LifeVal 基于美籍/多国时间使用调查构建 165 项日常任务基准，推动模型从聊天走向真正的个人代理。学术合作方面，模型证明了局部平滑猜想（全维度）、推翻了指数时间假设（ETH）、给出了规范量子场论的严格存在性证明——三大结果均已形式化为 Lean 代码，并按数学/CS/物理三个领域分别采用不同开放协作策略，探索 AI 生成发现的验证与归属新范式。

3. **Google DeepMind 的 PlanAssist 进入英国 15 个市政部门实战，规划审批耗时削减 58%**  
   面向占工作量 70% 的家庭扩建类申请，PlanAssist 自动校验文件、核对遗产保护/规划政策、生成带引用的评估报告。试点显示 70% 以上报告无需修改即可通过。工具由 Gemini 驱动，保持「人在回路」最终裁决权，计划 2027 年覆盖英格兰所有市政部门，支撑政府 2029 年前建成 150 万套住房目标。

4. **Cursor 发布 Agent SDK，将内部托管代理的构建框架开放给所有团队**  
   Agent SDK 以 TypeScript 定义提示、工具、连接、评测，单命令部署到 Cursor 基础设施或自托管容器。内置事件重放与 evals，支持多代理并行、子代理委派。PGA Tour 已用其构建全套软件工厂。标志着「以代码定义代理」从内部工具转为通用开发框架，降低了针对自家工作流定制代理的门槛。

5. **Hugging Face 推出 HOPE 二阶专家剪枝法与 Transformers Model Integration Contracts (MIC)，攻克 MoE 推理内存墙与集成测试盲区**  
   HOPE 引入专家两两交互矩阵 F，在 50% 剪枝率下平均排名第一，较最强一阶基线 REAP 在 Agentic 编码任务上提升 6.1%。MIC 将真实检查点收缩为保留所有层类型的微型 fixture（如 Llama 4 Scout 从 1086 亿参数降至 4470 万），配合使用路径与人工审核基线，在 CPU 上秒级捕获 UMT5 解码器可窥未来 token 等回归。两项成果均开源，直接服务于大模型落地的显存与可靠性痛点。

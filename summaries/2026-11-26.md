1. **Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2，展示前所未有的技术突破能力**

#### Anthropic Engineering Blog
**核心论点**：Messages API 从 Python 迁移到 Rust，五个月零停机上线，CPU 降 70%、首 token 延迟降 20%，核心是把生产系统变成验证器的影子测试+自动修复范式。  
**关键要点**：
- 迁移动因：流量 1800 倍增长，Python 对象创建/内存管理/任务切换开销成瓶颈；增量重写（解析器移 Rust）仅降 8-10% CPU 且引入三次跨语言调用新开销。
- 验证难点：Python 版持续演进（移动靶标）、模型非确定性输出、无法读取客户请求做逐行对比。
- 解法：新 Rust 服务影子模式跑真实流量，自动对比响应差异，差异派发 agent 修复再验证，形成闭环；把「现有系统作为 oracle」替代测试套件。
- 测试套件两大缺陷：耦合实现细节（移植时同步削弱断言，审计发现 100+ 处）；组合爆炸导致覆盖率极低（20 个二选项即百万组合）。
- 可行性探针先行：只跑核心模块编译与少量测试，发现嵌入式 MongoDB 依赖坏在 ARM 上，避免了「整体重写」的昂贵错误。
- 迁移分两路径：能跑旧系统→捕获行为再升级；跑不起来→先建最薄现代切片再扩展。安全等级 L0-L4 量化回归保护强度。
- 结果：零停机、不冻结功能发布、CPU/延迟双降，确立大规模重写新范式。
**值不值得深读**：**极其值得**——生产级迁移的教科书级复盘，解决「验证比生成难」的通用方法论。

### 今日要点

1. **OpenAI 发布 GPT-6.1 Terra：大幅降价、强化 Computer Use 与事实性**  
   新模型在 Agents’ Last Exam（专业级代理任务基准）中等推理下比 GPT-5.6 Terra 高 15 个百分点，成本仅为三分之一；终端编码基准 Terminal-Bench 4.0 最高推理下解决率 50.3%，是上一代 21.5% 的两倍多；内部幻觉基准低推理错误率从 53.6% 降至 16.7%。标准 API 定价 $1/1M in、$5/1M out，较 GPT-5.6 Terra 和 GPT-6.1 Sol 降 50%。这标志着「高性能、低成本、可大规模落地的 Computer Use 模型」正式进入开发者手中，将加速发票录入、技术图纸转 3D、视频剪辑等高频自动化场景的商业化。

**Welcome Beam: a 501B open model you can own, customize, and scale**  
**核心论点**：Reflection 实验室发布 Beam，501B 参数 MoE（23B 激活）、1M 上下文、Apache 2.0，主打编码与 Agentic 任务，Day-0 支持 transformers/vLLM/SGLang，自带 Rust 推理哈尼斯与 DFlash2 推测解码。  
**关键要点**：
- 架构：52 层、隐藏 5120、48Q/8KV 头、滑动窗口 512（43 层）+ 全局注意力（9 层），可缩放 Softmax 查询缩放替代位置编码。
- MoE：前 3 层稠密 SwiGLU，其余 49 层 256 专家（每专家 ~39M），DeepSeek-V3 分组路由（8 组×32 专家，保留 4 组顶 2 分数，组内取顶 8），无共享专家；专家输出归一化权重×2.5。
- 残差流：第 k 子层权重 `1/√k`，流保持恒定尺度；所有子层前后归一化，logits tanh softcap ±30（FP32）。
- 上下文：混合注意力使 KV 缓存增量 ~36 KiB/token（BF16），约朴素 1/6。
- 检查点：BF16 ~1 TB、FP8 适配 Hopper/Ampere、NVFP4 ~280 GB（Blackwell 原生），4×B200 (720 GB) 可长上下文并发服务。
- 生态：`transformers>=5.20.1` 一行 pipeline 调用；SGLang/vLLM 配置即用；Miles 支持全参数 RL；$10k Hub 信用激励二次开发。  
**值不值得深读**：**非常值得**——首个真正 Apache 2.0、前沿规模、可自托管深度定制的 Agent 基座模型，生态就绪、硬件规划指引清晰，直接降低「拥有前沿模型」门槛。

### 今日要点

1. **Anthropic 正式启动 IPO 路演，拟发行 8.25 亿股 A 类普通股，发行价区间 $70–$78，拟在纳斯达克上市，代码 "ANT"**。这是 AI 基础模型公司首次大规模公开募资，标志着 Anthropic 从「研究实验室」向「上市公司」转型，其估值定价将成为 OpenAI 等同类竞品的关键参照系；同时也会迫使其在安全治理、商业化节奏、股东压力之间寻找新平衡。

2. **Google DeepMind 发布 Gemini 4 Carbon，定位「最强模型」，在网络安全、长程 agentic 工作流、科学推理上达 SOTA，定价 $2/$10 per M tokens（12 月 1 日涨至 $4/$20）**。Carbon 在 CursorBench 4.0、WANDR、AutomationBench 排名第一且单任务成本仅为次优模型 1/2；配合 Antigravity `/swarm` 预览，可把单个 prompt 拆解为协同 agent 团队，标志着「模型即编排层」的产品化落地。

3. **AlphaProof Code 实现突破：AI agent 首次对广泛部署的 Signal 协议核心加密代码完成形式化验证，生成 600 万行 Lean 证明，仅耗时 4 周（人工通常需数年）**。这不仅证明 AI 能胜任最高等级的软件安全保障，更展示了「人机协同形式化验证」范式——专家定目标、agent 写证明、人类只审 1% 关键代码——可推广到医疗设备、电网等关键基础设施。

4. **Cursor Projects 推出多人协作模式：首个让「人类团队 + agent 队列」共享上下文、任务看板、代码审查的工作空间**。工程师可邀请同事进 Project，agent 之间跨席位自动通信避免冲突；on-call 交接时新接手者的 agent 能直接接管进行中任务。这把「单人 agent 工作流」升级为「团队级 agent 编排」，解决了上下文孤岛与交接丢失的痛点。

5. **Anthropic 重写版本控制系统 Scion，五个月完成从 git 迁移，日合并量从 2,500 跃升至 30,000+**。核心洞见：AI 编码让「源码管理」成为新瓶颈——git 为离线分布式设计，而 Anthropic 的客户端几乎全是在线 agent/CI。Scion 采用「客户端极简、服务端中心化、API 优先、稀疏按需 checkout」架构，提交、变基、合并全在服务端增量完成，无 packfile 维护。这是 AI 原生研发基建的首个规模化案例，预示其他高强度 AI 编码团队将面临相同压力。

**Redesigning source control at Anthropic**  
核心观点——AI 编码爆发使 git 成为瓶颈，Anthropic 自研 Scion 并在五个月内完成单体仓库迁移，日合并量从 2.5k 跃升至 30k+。

3. **Changeset 取代 commit**：写前日志条目存文件级变更，配合列式存储与列表索引，实现「按变更大小付费」而非「按仓库大小付费」。  
金句："The bottleneck, now, is all of the developer infrastructure built for human scale."
